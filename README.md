# PACE v2

A premium dark-green fitness and habit PWA prototype.

## Run
Open `index.html` in a browser or deploy this folder as a static site on Vercel.

## Included
- Premium forest/lime/mint visual redesign
- Daily goals, points and comeback action
- Time- and level-adjusted challenge suggestions
- Local squad challenge preview

## Important limitations
This is a front-end prototype. Progress and squad demo data are stored only in the browser on this device. There is no real account system, cloud database, friend invitations, shared live squad, automatic step tracking, payments, or moderation. Those require a backend and further development.
